## 1. Summary of Changes

Layer L3 eliminates flaw **S25-F02** across all four examination notification builders in `backend/src/lib/examNotifications.ts` and introduces a single shared persistence path:

1. **Shared Persistence Helper (`backend/src/lib/pushPersistence.ts`)**:
   - `persistPushResults`: Persists log records strictly downstream of actual `DispatchPushResult` arrays from `dispatchWebPush`. Each recipient user gets their exact authenticated outcome: `DELIVERED`, `FAILED`, `SKIPPED_NO_SUBSCRIPTION`, or `SKIPPED_UNCONFIGURED`.
   - `persistQuietHoursPushLogs`: Persists deferred quiet-hours notifications with status `DEFERRED_QUIET_HOURS` and `sentAt: null`, preserving the exact per-event title and body for daytime flushing.
2. **Four Builder Inversions in `examNotifications.ts`**:
   - `notifyResultReleased`: Dispatches via `dispatchWebPush` first during active hours, then records outcomes via `persistPushResults`. Reports `pushSentCount = deliveredCount` only (eliminating fabricated counts). During quiet hours, safely persists `DEFERRED_QUIET_HOURS` and returns `pushSentCount: 0`.
   - `notifyAdmitCardsReleased`: Dispatches first, persists downstream, reports real delivered count.
   - `notifyDatesheetPublished`: Dispatches first, persists downstream, reports real delivered count.
   - `notifyBulkJobCompleted`: Dispatches to triggering administrator first, persists downstream, reports real delivered count.
