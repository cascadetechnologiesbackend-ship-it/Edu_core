## 1. Summary of Changes
Resolved flaw `S15-F03` across the Class Hub and Subject Workspace:
1. **Replaced Silent Exception Swallowing**:
   - `frontend/src/app/(admin)/academics/classes/[classId]/page.tsx`: Removed `getTeachersList().catch(() => [])`. Replaced with explicit try/catch logging to `console.error` and captured `teachersError: string | null`.
   - `frontend/src/app/(admin)/academics/classes/[classId]/subjects/[classSubjectId]/page.tsx`: Removed `getTeachersList().catch(() => [])`. Replaced with explicit try/catch logging and captured `teachersError: string | null`.
2. **Admin Diagnostic Payload Wiring**:
   - Wired `getTeachingStaffDiagnostics(schoolId)` in both page servers for admins, passing live diagnostic metrics (`activeStaffCount`, `isTeachingCount`, `teacherRoleCount`, `conflictCount`) into `ClassHubClient` and `SubjectWorkspaceClient`.
3. **Faculty Loading Warning Banners**:
   - Both `ClassHubClient` and `SubjectWorkspaceClient` render an amber alert banner when `teachersError && isAdmin`:
     `Faculty Loading Notice: Unable to load teaching faculty ({teachersError}). [Check HR Faculty ->]`
4. **Diagnostic-Driven Empty States inside Modals**:
   - **Assign Section Teacher Modal** (`SubjectWorkspaceClient.tsx`):
     When `allTeachers.length === 0`, replaces the silent `<select>` with a clear diagnostic card showing active staff and teaching classification counts with a direct link to `/hr?tab=designations`.
     Disables the *Save Allocation* button when no teacher is available or selected.
   - **Add Section Modal** (`ClassHubClient.tsx`):
     When `allTeachers.length === 0`, provides an amber guidance card showing live diagnostics and HR link.
   - **Attach Subject Modal** (`ClassHubClient.tsx`):
     When `allTeachers.length === 0`, provides an amber guidance card showing live diagnostics and HR link.
   - **Substitution Modal** (`ClassHubClient.tsx`):
     Uses standardized `displayName` fallback.
