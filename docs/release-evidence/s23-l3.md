## 1. Flaw Closure: S23-F02 (Librarian Console Fabrications)

Prior to Layer 3, `(librarian)/librarian/dashboard/page.tsx` rendered hardcoded JSX literals:
- Total Book Volume: `4,850`
- Currently Issued: `142 Books`
- Overdue Returns: `8 Books`
- Catalog Categories: `18`

All hardcoded literals have been permanently eliminated. The page now authenticates via `requireAuth(["SUPER_ADMIN", "SCHOOL_ADMIN", "LIBRARIAN"] as const)`, scopes to `requireSchool(ctx)`, and queries live metrics via `getLibrarianConsoleMetrics(school.id)` wrapped in `assertQueryBudget(..., { maxQueries: 6, label: "Librarian Dashboard" })`.

| Metric | Source of Truth | Populated Behavior | Empty Library Behavior |
| :--- | :--- | :--- | :--- |
| **Total Book Volume** | `books` and `book_copies` | Live physical copies total (and available count) | `0` (`"0 physical copies in inventory"`) |
| **Currently Issued** | `book_issues` (unreturned, active) | Live count of issued books | `0 Books` (`"No books currently checked out"`) |
| **Overdue Returns** | `book_issues` (`dueDate < now`, unreturned) | Live count with red alert styling & `"Late fine applicable"` | `0 Books` (`"No overdue returns"`, normal emerald/slate styling) |
| **Catalog Categories** | `books.category` distinct values | Count + top 3 active subjects | `0` (`"No categories configured"`) |
