# Layer L5 Release Evidence: Guard Module & Hardened Write Paths

**Specification**: `S16-DUAL-ROLE-TEACHER-AUTH`  
**Layer**: `L5` (Guard module + hardened write paths: P0/P1 closures)  
**Commit**: `7343450`  
**Date**: 2026-10-24  
**Status**: COMPLETE  

---

## 1. Vulnerability Closures & Guards Delivered

1. **New Guards Module (`backend/src/lib/teacherAuthGuards.ts`)**:
   - `TeacherScopeError` (403/423) with machine-readable error codes:
     - `SUBJECT_TEACHER_FORBIDDEN`: Raised when an unallocated teacher attempts to read/write marks or period attendance.
     - `CLASS_TEACHER_OVERRIDE_REQUIRED`: Raised when a non-class teacher attempts homeroom operations (daily roll-call, leave approval, full Student 360).
     - `CROSS_SECTION_STUDENT_TAMPER_ATTEMPT`: Raised when a write payload injects student IDs not enrolled in the section roster.
     - `MARKS_WINDOW_LOCKED`: Raised (423) when attempting to edit finalized marks.
   - Guard functions:
     - `assertSubjectTeacherPermission`: Validates subject teacher allocation (admin bypass supported).
     - `assertClassTeacherOverride`: Validates homeroom assignment.
     - `assertStudentRosterMembership`: Validates that all student IDs belong to the target section roster.
     - `assertStudent360Access`: Authorizes full homeroom 360 vs restricted subject view.

2. **Exam Marks Closure (S16-F01 & S16-F02)**:
   - In `getExamMarksRoster`: Enforces teacher allocation check; unallocated teachers cannot inspect marks rosters.
   - In `saveExamMarks`:
     - Checks `assertSubjectTeacherPermission(ctx.userId, payload.sectionId, payload.subjectId)`. Closes S16-F01.
     - Checks `assertStudentRosterMembership(studentIds, payload.sectionId, school.id, tx)`. Closes S16-F02 IDOR.
     - Enforces lock window with code `MARKS_WINDOW_LOCKED` (423).

3. **Attendance & Leave Split (S16-F05)**:
   - In `saveTeacherAttendanceRoster`:
     - Daily homeroom roll-call (`periodId: null`): Requires `assertClassTeacherOverride`.
     - Period attendance (`periodId != null`): Requires `assertSubjectTeacherPermission` for that period's subject and section.
     - Checks `assertStudentRosterMembership`.
   - In `decideLeaveRequest`:
     - Queries student's section and requires `assertClassTeacherOverride`. An unallocated teacher can no longer approve or reject homeroom leave requests.
