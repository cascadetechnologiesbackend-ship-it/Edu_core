## 2. Delivered Domain Query Engine (`backend/src/lib/roleConsoleEngine.ts`)

The authoritative role console engine provides 3 multi-tenant domain query methods wrapped in `withTenant(schoolId)`:

### A. `getPrincipalConsoleMetrics(schoolId, options?)`
- **Active Class Sections**: Live count of sections where `schoolId = schoolId` and `isActive = true`.
- **Active Teaching Staff**: Live count of active staff where `designation.isTeaching = true` (or all active staff if designations unconfigured).
- **Today's Student Attendance**: Aggregated from `studentAttendance` where `attendanceDate` falls within today. Returns `ratePercent`, `totalMarked`, and `formattedPercent`. If 0 records exist, returns `isMarkedToday: false`, `formattedPercent: "Not Marked"`.
- **Pending Exam Marks Verifications**: Live count of `examMarksLocks` where `status = "SUBMITTED"` (awaiting principal verification and lock).
- **Staff Attendance Rate (OD3)**: Live rate if `staffAttendance` records exist for today; `null` otherwise.

### B. `getLibrarianConsoleMetrics(schoolId, options?)`
- **Total Copies**: Computed across active books and active physical copies (`bookCopies.deletedAt IS NULL`).
- **Available Copies**: Total physical copies currently on rack (`isAvailable = true`).
- **Currently Issued**: Live count of `bookIssues` where `returnedAt IS NULL` and `status != 'RETURNED'`.
- **Overdue Returns**: Live count of unreturned checkouts where `dueDate < now` or `status = 'OVERDUE'`.
- **Categories**: Distinct count and breakdown of active book categories.

### C. `getTransportConsoleMetrics(schoolId, options?)`
- **Active Fleet Vehicles**: Count of vehicles where `deletedAt IS NULL`.
- **Configured Routes & Stops**: Active routes and total pickup stops.
- **Opt-In Students**: Distinct count of students with active `studentBusPasses`.
- **Real Maintenance Alerts**: Identified when `fitnessCertExpiryDate` or `insuranceExpiryDate` is expired or expiring within 30 days.
- **Live GPS Recency**: Telemetry recency derived from `gpsPings` timestamp (e.g. `"Live (just now)"`, `"Active (3m ago)"`, or honest `"No recent GPS signal"` when pings are stale or absent).
