## 1. Work Delivered

1. **Unified Class Teacher Action (`frontend/src/app/(admin)/academics/actions/teacher-assignment.actions.ts`)**:
   - `upsertClassTeacherAssignment(params: UpsertClassTeacherParams)`:
     - Scoped strictly by `schoolId` and section's `academicYearId`.
     - Validates Condition B (at most one homeroom per teacher per academic year).
     - Deactivates prior active row for the section (`is_active = false`, `effective_to = todayStr`).
     - Inserts new active row in `class_teacher_assignments`.
     - Transactionally mirrors assignment into `sections.classTeacherId` for backward read compatibility.
     - Automatically calls `clearTeacherScopeCache()` and revalidates relevant Next.js routes.
   - `checkClassTeacherAssignmentConflict(teacherId, sectionId)`:
     - Pre-save query detecting if the selected teacher already actively leads another section in the same academic year.
     - Returns machine-readable conflict metadata (`teacherId`, `existingSectionId`, `existingSectionName`, `existingClassName`, `message`).

2. **Admin Write Path Routing (`frontend/src/app/(admin)/academics/actions.ts`)**:
   - `saveSection`:
     - Routes all class teacher assignments through `upsertClassTeacherAssignment`.
     - Surfaces conflict info when attempting to assign an already-allocated teacher without `forceTransfer`.
     - Supports `forceTransfer: true` to seamlessly transfer a teacher while deactivating their prior assignment and clearing the previous section's mirror.
   - Re-exports `upsertClassTeacherAssignment` and `checkClassTeacherAssignmentConflict`.

3. **Subject Teacher Allocation Hardening (`frontend/src/app/(admin)/academics/actions/class-setup.actions.ts`)**:
   - `assignSectionTeacher`:
     - Extended to populate `academicYearId` (derived from classSubject -> class), `isPrimary` (default true), and `periodsPerWeek` (default 5).
     - Enforces uniqueness under `sst_active_primary_unique_idx`.
   - `createClassSetup`:
     - When sections are created with initial `classTeacherId`, mirrors the designation into `class_teacher_assignments` rows.

4. **S15-Era Admin Conflict Warning UI (`ClassHubClient.tsx`) (S16-F09)**:
   - Wired `assignmentConflict` state into the Edit Section modal.
   - Displays clear warning card: "Class Teacher Allocation Conflict: Teacher is already assigned as Class Teacher of Grade X Section Y for this academic year."
   - Provides a one-click "Transfer to Section {name}" button executing `saveSection({ ..., forceTransfer: true })`.
