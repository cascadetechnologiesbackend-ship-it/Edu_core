## 1. Summary of Layer L7 Scope & Invariants

Layer L7 enforces and certifies **AC7** and **Standing Constraints**:
1. **Teacher CRUD Guard Matrix**:
   - `createHomeworkAction`: Only teachers holding active allocations (or homeroom class teachers) for the specified class-subject and sections can author homework. Calls outside scope reject with `Unauthorized`.
   - `markTopicTaughtAction`: Only allocated subject teachers can toggle topic coverage status.
2. **Displacement Boundary (Immediate Revocation)**:
   - When a teacher assignment is displaced (e.g. admin assigns incoming teacher), the teacher scope cache is evicted and any subsequent homework authoring attempts by the displaced teacher immediately reject with `Unauthorized` (strict S18 L3 parity).
3. **Parent Timeline DPDP & Child Isolation**:
   - `resolveParentWards`: Only returns active students associated with `ctx.userId` in the parent's verified school tenant.
   - Unauthorized attempts to access alien children's IDs return empty datasets.
   - `deriveParentFeed`: Generates timeline cards scoped strictly to verified student IDs; no student cross-leakage.
4. **Multi-Tenant Two-School Isolation & Admin Aggregates**:
   - Teacher allocations and timetable periods in School A are completely invisible to queries executed in School B (`crossTenantScope.allSectionIds.length === 0`).
   - Admin roles retain aggregate visibility across all sections within their authenticated school.
