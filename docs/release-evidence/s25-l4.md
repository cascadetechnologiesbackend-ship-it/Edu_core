## 1. Summary of Changes

Layer L4 eliminates flaw **S25-F03** by resolving cross-recipient notification payload corruption during quiet-hours flush and wires the missing queue scheduler producers:

1. **Payload Isolation & Grouped Dispatch**:
   - In `backend/src/workers/notificationQueueWorker.ts`, `flushQuietHoursNotifications` no longer broadcasts `logs[0]?.title` and `logs[0]?.body` to all queued recipients in a school.
   - Now sub-groups deferred notifications by exact payload (`title + body`), dispatching each distinct group only to the recipients who were actually scheduled to receive that exact message.
2. **Post-Dispatch Status Updates (Zero Write-Before-Dispatch)**:
   - Eliminates the previous write-before-dispatch vulnerability where up to 500 logs were unconditionally marked `DELIVERED` before `dispatchWebPush` was called.
   - Now updates each log row strictly *after* `dispatchWebPush` returns, setting `status: res.status` and setting `sentAt` only if `status === "DELIVERED"`.
3. **Quiet-Hours Gate & Clock Override**:
   - Defers flush and returns `{ flushedCount: 0, skippedQuietCount: 1 }` whenever invoked during quiet hours window (21:00–07:00 IST), supporting optional clock overrides for testing.
4. **BullMQ Scheduler & Cron Producer**:
   - Added `registerNotificationSchedulers()` in `notificationQueueWorker.ts`:
     - Repeatable BullMQ job for daily quiet-hours flush at 07:05 IST (`5 7 * * *` Asia/Kolkata).
     - Repeatable BullMQ job for SMS drain every 15 minutes (`every: 15 * 60 * 1000`).
   - Added `frontend/src/app/api/cron/notifications/route.ts` protected by `withCronAuth` (`CRON_SECRET` Bearer auth) allowing serverless or external scheduler triggers.
