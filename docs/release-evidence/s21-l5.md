## 1. Scope & Delivered Features

- **F13 (Mobile Reflow Subsystem)**:
  - Eliminated 968px horizontal table overflow on mobile viewports (< 768px / 390px iPhone baseline).
  - **Responsive Viewport Splitting**:
    - Desktop (`hidden md:block`): Retains full 6-column weekly timetable grid overview with sticky period header column for desktop power users.
    - Mobile (`block md:hidden`): Renders 6-button day tabs (`MON | TUE | WED | THU | FRI | SAT`) showing exactly one day column at a time.
  - **Single-Day Period Card Stack**:
    - Renders periods 1..8 as full-width interactive cards within the 390px viewport.
    - Each card displays period name, start/end time, period type badge, manual override badge (`Manual`), subject name, teacher email, and room number.
    - Empty slots render dashed "+ Add" trigger with clear affordance.
  - **Touch Target Ergonomics**:
    - Day tabs: `py-2 min-h-[38px]`.
    - Period cards: `p-3 min-h-[64px]` with active press feedback (`active:scale-[0.99]`).
    - Modal triggers and actions: `min-h-[38px]`.
  - **Generator Preview Modal Mobile Reflow**:
    - Workload fit stat cards reflow from 3 columns to 1 column on mobile (`grid grid-cols-1 sm:grid-cols-3`).
    - Clash cards and needs-assignment lists wrap cleanly with zero horizontal scroll.
    - Action buttons stack vertically on mobile (`flex-col-reverse sm:flex-row`).

## 2. Invariants & UI/UX Standards

### 2.1 Universal Scroll-and-Click Law (R7)
- Strict vertical scrolling only.
- Zero horizontal overflow at 390px breakpoint (`scrollWidth === clientWidth`, `overflow-x: hidden`).
- Multi-column timetable grid reflows to single-day column with day tabs on mobile.

### 2.2 Click-to-Depth Parity
- Tapping any period card on mobile triggers `handleOpenSlot(activeMobileDay, period)` at the exact same depth and interactive capability as desktop table cell clicks.

### 2.3 Honesty Law (AC-5)
- Success toast and feedback strip only render after server-confirmed persistence (`commitSectionTimetable` returns `success: true`). Zero simulated success states.
