## 1. Flaw Closure: S23-F01 (Principal Console Fabrications)

Prior to Layer 2, `(principal)/principal/dashboard/page.tsx` rendered hardcoded JSX literals:
- Class Sections: `24`
- Teaching Staff: `48` with `96% Daily Attendance`
- Average Student Attendance: `94.2%`
- Pending Exam Marks: `2 Classes`

All hardcoded literals have been permanently removed. The page now calls `requireSchool(ctx)` and fetches live metrics via `getPrincipalConsoleMetrics(school.id)` wrapped in `assertQueryBudget(..., { maxQueries: 6 })`.

| Metric | Source of Truth | Populated Behavior | Empty School Behavior |
| :--- | :--- | :--- | :--- |
| **Class Sections** | `sections` table (`isActive: true`) | Live section count | `0` (`"0 active class sections"`) |
| **Teaching Staff** | `staff` table (`designations.isTeaching = true`) | Live faculty count | `0` (`"0 active faculty members"`) |
| **Staff Attendance Today (OD3)** | `staffAttendance` table (today) | Live percentage if marked | Cleanly omitted if unpopulated (never fabricated 96%) |
| **Student Attendance Today** | `studentAttendance` table (today) | Live percentage and present/total breakdown | `0.0%` (`"Attendance not taken today"`) |
| **Pending Exam Marks** | `examMarksLocks` table (`status: "SUBMITTED"`) | Live submitted count awaiting principal lock | `0 Classes` (`"All marks verified & locked"`) |
