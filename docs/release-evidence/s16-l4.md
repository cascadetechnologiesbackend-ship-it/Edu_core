## 1. Scope Hardening Delivered (`backend/src/lib/teacherEventEngine/scopeResolver.ts`)

1. **Academic Year & Temporal Window Filtering (S16-F06)**:
   - Scoped strictly by `schoolId` and active `academicYearId`.
   - Class Teacher assignments and Subject Teacher allocations now enforce:
     `effectiveFrom <= todayStr AND (effectiveTo IS NULL OR effectiveTo >= todayStr)`.
   - Future-scheduled allocations no longer prematurely grant access.

2. **Single Source of Truth for Homeroom / Class Teacher (Condition B)**:
   - Queries `class_teacher_assignments` (`is_active = true`, effective dates valid).
   - Preserves backward compatibility by unioning with `sections.classTeacherId` where legacy rows exist.

3. **Grade-Wide Fallback Collision Fix (S16-F06)**:
   - Queries all active section-subject overrides across the school/academic year.
   - When evaluating class-wide fallback mappings (`classSubjects.assignedTeacherId`), sections that have an active section override for that subject are strictly suppressed.
   - Prevents phantom dual ownership where both a section-override teacher and a class-default teacher had simultaneous rights to a section's subject.

4. **Backward-Compatible Output Shape**:
   - Return shape `TeacherScope` (`classTeacherSections`, `teachingSections`, `allSectionIds`, `scheduledPeriods`) preserved.
   - Existing consumers in grading, attendance, homework, and timetable continue working without breaking changes.
