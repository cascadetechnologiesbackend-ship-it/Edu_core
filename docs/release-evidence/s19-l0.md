## 2. Flaw Investigation & Root-Cause Audit

### S19-F01: Teacher My Day Timeline Not Timetable-Truthed ("Free period" Everywhere)
- **Investigation**: In `frontend/src/app/(teacher)/teacher/classes/classesActions.ts` (`getTeacherMyDayTimeline`), `getDayOfWeekEnum(targetDate)` converts Sunday to "MONDAY". It queries `timetablePeriods` filtered by `teacherId = ctx.userId`. When no timetable rows exist or on weekends, it falls back to 8 default empty periods with `isFree: true`.
- **Verdict**: **DEFECT**. Silent fallback to "Free period" masks missing setup. When allocations exist but zero timetable rows are published, the engine must render an actionable `setup-missing` state: *"Your timetable is not published — notify school admin"*, never a silent free day.

### S19-F02: No Now-Cockpit in Teacher App
- **Investigation**: `frontend/src/app/(teacher)/teacher/dashboard/page.tsx` renders `TeacherTodayStrip` and a cards stream. Opening the app mid-period does not present the current active period, remaining time, one-tap roll call, or quick shortcuts.
- **Verdict**: **UNWIRED**. Needs dedicated Now-Cockpit atop the feed with live period status, one-tap attendance launcher, and day progress ring.

### S19-F03: No Calendar Awareness (Sunday Rendered as Completed Instructional Day)
- **Investigation**: In `frontend/src/components/teacher/TeacherTodayStrip.tsx` (line 36): `const isCalm = isDayComplete || activeCardsCount === 0;`. On Sunday, `activeCardsCount` is 0, so `isCalm` evaluates to true, rendering *"All sections marked. All students accounted for. Day Marked Complete"* on a Sunday.
- **Verdict**: **DEFECT**. Calendar awareness state machine missing. Sunday and holidays (`academicCalendarEvents` with `isWorkingDay = false`) must render an honest Rest Day state with tomorrow's preview, never false completion.

### S19-F04: Teacher Authoring CRUD Missing or Non-Operational
- **Investigation**:
  - `frontend/src/app/(teacher)/teacher/homework`: Route exists with `createHomeworkAction`, but is NOT linked in `MORE_SECTIONS` of `/teacher/more/page.tsx`.
  - `frontend/src/app/(teacher)/teacher/syllabus`: Route exists with read queries, but has NO write action (`markTopicTaughtAction`) and is NOT linked in `/teacher/more/page.tsx`.
  - Lesson plan authoring has an admin write action (`saveLessonPlan` in `academics/actions.ts`), but no direct teacher authoring interface in Teacher PWA.
- **Verdict**: **PARTIALLY UNWIRED / UNLINKED**. Must add `markTopicTaughtAction`, wire teacher lesson plan authoring, add section targeting to homework create, and link under an "Academics & Authoring" category in `/teacher/more/page.tsx`.

### S19-F05: Event Chain to Family & Admin Broken/Untested
- **Investigation**: Homework creation emits `AssignmentPublishedEvent` to `domainEvents`, but end-to-end multi-surface reflection (Teacher create -> Student PWA -> Parent Timeline -> Admin Workspace) is not covered by a unified reflection test.
- **Verdict**: **UNTESTED CHAIN**. Must extend reflection matrix suite with `s19-reflection-matrix.test.ts`.

### S19-F06: Parent App Lacks Event/Timeline-Driven Components
- **Investigation**: `ParentFeedContainer.tsx` stacks pinned cards and unpinned cards. Needs attention cards (fees) repeat repeatedly. There is no chronological timeline with date anchors, coming-up rail, or empty state CTAs.
- **Verdict**: **UNWIRED TIMELINE**. Must create `ParentTimeline.tsx` and restructure feed to lead with summary count row + timeline.

### S19-F07: Data-Quality Defects
- **Investigation**:
  - *"Annual Fee Fee"*: `ParentDashboardPage.tsx` maps `"ANNUAL"` to `"Annual Fee"`, and `PaymentCard.tsx` formats `{termName} Fee`, resulting in `"Annual Fee Fee"`.
  - *Attendance 0.0% vs 100%*: In `frontend/src/app/(parent)/parent/profile/page.tsx`, `totalDays = attRows.length || 1` divides `0` by `1` when attendance records are empty, yielding 0.0% while header defaults to 100%.
  - *"Valbhav null"*: `decryptData(lastName)` returning `null` when interpolated in template literals evaluates to string `"null"`.
- **Verdict**: **DATA QUALITY DEFECTS**. Fix fee string deduplication, unified attendance calculation function, and name sanitizer.

### S19-F08: Unmarked Periods Leave No Operational Trace
- **Investigation**: No pending-chips exist on the day timeline to nudge completion of past own-periods that lack attendance marks.
- **Verdict**: **UNWIRED PENDING LOOP**. Add pending-period chips to Now card and day timeline with one-tap marking.

### S19-F09: Wide Tables Force Horizontal Scrolling on Mobile PWA
- **Investigation**: `HomeroomWorkspaceView.tsx` compiled report cards table renders multiple subject columns and remarks inputs in a single table row, overflowing 390px mobile viewports.
- **Verdict**: **DEFECT (UNIVERSAL SCROLL/CLICK LAW VIOLATION)**. Reflow wide tables into responsive card-per-student / expandable rows.
