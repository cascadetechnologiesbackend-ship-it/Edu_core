## 1. Summary of Changes

Layer L4 addresses **AC4, AC8, AC9, AC10** by establishing and automating the verification of the complete multi-surface reflection matrix:
$$\text{Teacher Authoring} \longrightarrow \text{Domain Events} \longrightarrow \begin{cases} \text{Student PWA (Homework Center)} \\ \text{Parent PWA (Feed \& Timeline Engine)} \\ \text{Admin Console (Subject Workspace Trajectory)} \end{cases}$$

### A. Whole-Chain Reflection Matrix Suite (`s19-reflection-matrix.test.ts`)
- Created automated CI reflection suite at `frontend/src/app/(admin)/hr/__tests__/s19-reflection-matrix.test.ts`.
- Validates the following 4 distinct surfaces in a single unified flow:
  1. **Surface 1: Teacher Authoring Surface**:
     - Teacher with active S16 teaching allocations creates homework with multi-section targeting (`['sec-10a', 'sec-10b']`).
     - Publishes `assignments` rows for all targeted sections in an atomic transaction.
     - Emits `AssignmentPublishedEvent` domain events for asynchronous/downstream processors.
     - Teacher toggles syllabus topic taught status (`markTopicTaughtAction`), creating completed `lessonPlans` records and emitting `SyllabusTopicCoveredEvent`.
  2. **Surface 2: Student Homework Center**:
     - Student Aarav in targeted section `10-A` queries homework and receives the authored homework in the `pending` bucket with full metadata (subject name, due date, max marks).
     - Student in an unassigned section (`10-C`) sees zero assignments (strict section and tenant boundary).
  3. **Surface 3: Parent Feed & Timeline Engine (`deriveParentFeed`)**:
     - Feeds child snapshot containing newly authored homework into `deriveParentFeed`.
     - Produces `HomeworkPostCard` / `HomeworkCard` tagged with the child's name (`wardName`), subject name, and countdown badge (`Due tomorrow`).
  4. **Surface 4: Admin Subject Workspace Trajectory**:
     - Curriculum query calculates syllabus trajectory dynamically: 1 of 2 topics completed ($50\%$).
     - Workspace reflects all active assignments across all sections.

### B. Security & S16 Allocation Enforcement
- Integrated negative test verifying that unauthorized teachers (`teacher-999` with no S16 allocation) are strictly blocked with an `Unauthorized` error when attempting to post homework or modify syllabus progress.
