## 1. Flaw Closure: S23-F03 (Transport Manager Console Fabrications)

Prior to Layer 4, `(transport-manager)/transport/dashboard/page.tsx` rendered hardcoded JSX literals:
- Bus Fleet Vehicles: `8 Vehicles` with blanket claim `Active GPS Tracking`
- Configured Routes: `12 Routes` with `45 Pickup Stops`
- Opt-In Students: `320 Students` with `Auto Transport Fee Assigned`
- Maintenance Alert: `1 Vehicle` with `Due for fitness check`

All hardcoded literals have been permanently removed. The page authenticates via `requireAuth(["SUPER_ADMIN", "SCHOOL_ADMIN", "TRANSPORT_MANAGER"] as const)`, scopes to `requireSchool(ctx)`, and queries live metrics via `getTransportConsoleMetrics(school.id)` wrapped in `assertQueryBudget(..., { maxQueries: 6, label: "Transport Manager Dashboard" })`.

| Metric | Source of Truth | Populated Behavior | Empty Fleet Behavior |
| :--- | :--- | :--- | :--- |
| **Bus Fleet Vehicles** | `vehicles` table (`isActive: true`) | Live vehicle count + real GPS telemetry recency label | `0 Vehicles` (`"0 vehicles registered"`) |
| **GPS Status / Tracking** | `gpsPings` within 15 minutes | `"Live (just now)"` or `"Active (Xm ago)"` | `"No recent GPS signal"` (honest, no blanket claim) |
| **Configured Routes** | `routes` and `routeStops` tables | Live active route count + live total pickup stops count | `0 Routes` (`"0 pickup stops defined"`) |
| **Opt-In Students** | `busPasses` table (`status: "ACTIVE"`) | Live student pass count + fee assigned indicator | `0 Students` (`"No student passes issued"`) |
| **Maintenance Alerts** | `vehicles` (`fitnessCertExpiryDate` / `insuranceExpiryDate`) | Count + first vehicle registration plate & specific issue | `0 Vehicles` (`"All vehicles fitness-certified"`, normal border) |
