## 1. Objectives & Changes Made

1. **Populated Section, Class, and Subject Context on Substitutions**:
   - In `backend/src/lib/teacherEventEngine/snapshotAssembler.ts`, expanded `timetableSubstitutions` query to fetch relations:
     `section: { with: { class: true } }`, `subject: true`, and `timetablePeriod: { with: { section: { with: { class: true } }, subject: true } }`.
   - Populated `sectionName`, `className`, and `subjectName` accurately on `SubstitutionItem`.
   - Eliminated empty string brackets `( -  )` in card title and summary.
2. **Integrated Schedule Clash Detection**:
   - Integrated `checkSubstitutionClash(s.id, teacherUserId, txDb, schoolId)` from `substitutionClash.ts`.
   - For incoming substitution requests, checks if the educator already has an assigned period on their own schedule during that day and time.
   - Computes `hasConflict: boolean` and `conflictReason: string | undefined`.
3. **Card & UI Truth**:
   - `deriveTeacherFeed` surfaces `Cover Period N (Section)` in title and `(Class-Section Subject)` with `Warning: Clash with your timetable.` in summary.
   - `SubstitutionFeedCard.tsx` activates its warning chip (`countdownChip="Schedule Conflict"`) and alert banner when `hasConflict` is true.
