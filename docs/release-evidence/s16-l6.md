## 1. Capabilities & Surfaces Delivered

1. **Dual Workspace Server Actions (`classesActions.ts`)**:
   - `getTeacherWorkspaceScope()`:
     - Derives canonical dual-workspace state from `resolveTeacherScope`.
     - Returns `homeroomSection` (`sectionId`, `classId`, `className`, `sectionName`, `studentCount`, `roomNumber`) when designated as active Class Teacher.
     - Returns `subjectAllocations[]` with `(Class-Section, Subject)` tuples, `isAlsoHomeroom` indicators, and enrolled student counts.
   - `getCompiledReportCardMatrix(sectionId, termId)`:
     - Asserts `assertClassTeacherOverride(ctx.userId, sectionId)`. Throws 403 `CLASS_TEACHER_OVERRIDE_REQUIRED` for unallocated teachers.
     - Compiles student x subject marks grid with total scores, percentages, and `homeroomReportRemarks`.
     - Identifies `isMySubject` per column for instructional navigation.
   - `saveHomeroomRemarks({ studentId, academicTermId, remarks, conductGrade })`:
     - Asserts `assertClassTeacherOverride(ctx.userId, student.currentSectionId)`.
     - Upserts into `homeroomReportRemarks` with `signedOffById = ctx.userId`.
   - Hardened `getTeacherStudent360Drawer`:
     - Calls `assertStudent360Access`.
     - `FULL_HOMEROOM`: Full cross-subject marks, categorical fee status badge (`PAID` / `DUE` / `OVERDUE`), and homeroom holistic remarks.
     - `RESTRICTED_SUBJECT`: Fee status omitted completely, exam marks and homework filtered strictly to subjects taught by the caller.

2. **UI Architecture & Components**:
   - `TeacherScopeContext.tsx`: React Context and `useTeacherScope` hook managing `workspaceScope`, `activeWorkspace` (`"homeroom"` | `"subject"`), and selected subject allocation.
   - `TeacherWorkspaceSwitcher.tsx`:
     - Dual-mode segmented pill switch. Homeroom tab is conditionally rendered only when `homeroomSection !== null`.
     - Displays Class Teacher badge and allocation chips for multi-class navigation.
   - `HomeroomWorkspaceView.tsx`:
     - **Compiled Report Cards**: Term selector, student x subject matrix, conduct grade selector, holistic remarks input, and "Sign Off" action.
     - **Homeroom Roster & 360**: Roster cards with categorical fee status badges and one-tap launch to `Student360Drawer`.
     - **Daily Roll-Call Register**: Seamless embed of `AttendanceWorkbench` initialized with `homeroomSection.sectionId` for morning attendance.
   - `Student360Drawer.tsx`:
     - DPDP statutory fee protection: renders fee status badge strictly for authorized Class Teacher / Admin; displays restricted subject notice otherwise.
     - Displays homeroom teacher remarks and conduct grade when available.
