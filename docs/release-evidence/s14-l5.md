## 1. Implementation Summary

1. **Commit Safety & Navigation Guard (`frontend/src/app/(admin)/academics/SubjectMappingTab.tsx`)**:
   - Added an active `beforeunload` event listener triggered whenever `dirtyKeys.size > 0`. If an administrator attempts to leave or reload the page with staged curriculum matrix edits, the browser alerts them that unsaved changes will be lost.
   - Updated the slide-over drawer action button text from `"Apply Changes"` to `"Stage in Matrix (Save All to persist)"`, making it transparent that drawer modifications update local staged state until the administrator clicks `"Save All"` in the sticky matrix bar.

2. **Empty-State Diagnostic Guidance (`frontend/src/app/(admin)/academics/SubjectMappingTab.tsx`)**:
   - In the drawer Lead / Assigned Teacher section, when `teachers.length === 0`, replaced the bare select dropdown with a diagnostic warning banner:
     - Warning header: "No active teaching staff found"
     - Explanatory note: "Teachers must be classified with teaching designations in HR to appear here."
     - Deep link: "Go to HR Designations &rarr;" linking to `/hr?tab=designations`.

3. **Section Modal Class Teacher Guidance (`frontend/src/app/(admin)/academics/ClassroomsTab.tsx`)**:
   - When creating or editing sections and `teachers.length === 0`, rendered a prominent amber warning card instead of an unhelpful empty dropdown.
   - Included explanatory copy stating that class teachers must be assigned teaching designations in HR, with a direct link to `/hr?tab=designations`.
