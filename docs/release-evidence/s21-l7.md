## 1. Scope & Delivered Architecture

Sprint S21 touches four major administrative user interfaces:
1. `QuickTimetable.tsx` (Timetable Builder UI & Generator Preview Modal)
2. `ImportExportModal.tsx` (Universal Data Import Modal & CSV Exporter)
3. `school-setup/page.tsx` (School Setup Hub & Operational Health Scorecard)
4. `settings/page.tsx` (Settings Overview & Dual-Score Progress Telemetry)

Under **Requirement R7 (Universal Scroll-and-Click Law)**, all touched surfaces must satisfy:
- **Zero Horizontal Overflow at 390px Viewport**: Strict vertical scrolling only. `document.documentElement.scrollWidth <= 390px`. No wide tables, side-by-side grids, or fixed pixel widths $> 390$px on mobile.
- **Card-Per-Record & Day Tab Reflow**: Wide multi-day timetable matrices reflow to single-day vertical card stacks selected via responsive day tabs.
- **Touch Target Ergonomics**: All interactive elements (tabs, action buttons, links) enforce minimum touch heights $\ge 38$px (`min-h-[38px]`, `min-h-[40px]`, or `min-h-[44px]`).
- **Strict Click Budgets**: Primary administrative tasks complete in 2 to 4 taps with click-to-depth navigation.

## 2. Component Reflow Implementations

### 2.1 QuickTimetable Builder UI (`frontend/src/components/academics/QuickTimetable.tsx`)
- **Desktop Grid Separation**:
  - Desktop view (`hidden md:block overflow-x-auto`): Wide 6-day table (Monday–Saturday) with sticky left period timing column.
  - Mobile view (`block md:hidden space-y-3`): Desktop table completely hidden; rendered as a 6-button day tabs navigation grid (`grid grid-cols-6 gap-1 bg-gray-100 dark:bg-slate-800/80 p-1.5 rounded-2xl`).
- **Mathematical Viewport Proof (390px)**:
  $$\text{Content Width} = 390\text{px} - 24\text{px (page margins)} = 366\text{px}$$
  $$\text{Usable Width} = 366\text{px} - (5 \times 4\text{px gaps}) - 12\text{px (container padding)} = 334\text{px}$$
  $$\text{Per-Tab Button Width} = \frac{334\text{px}}{6} \approx 55.67\text{px}$$
  A width of $55.67$px comfortably fits 3-letter uppercase day codes (`MON`, `TUE`, `WED`, `THU`, `FRI`, `SAT`) with zero horizontal overflow.
- **Single-Day Period Card Stack**:
  - Displays periods 1 through 8 in a vertical stack (`space-y-2`) for the selected day tab.
  - Each card renders: period name, time window (`font-mono text-gray-400`), non-regular type badge (`periodType !== "REGULAR"`), subject name, teacher email, room number, manual override badge (`isManualOverride: true` rendered with purple badge), and `+ Add` / `Edit` button.
- **Generator 3-Tier Preview Modal**:
  - Rendered inside `AppModal size="2xl"` with vertical card stacking (`space-y-4`).
  - Workload fit report, concurrency clash alert box, teacher needs-assignment report, and persistence metrics reflow to single-column blocks with full-width buttons on mobile.

### 2.2 Universal Import/Export Modal (`frontend/src/components/ui/ImportExportModal.tsx`)
- **Modal Container**:
  - Uses `p-4 sm:p-6 max-w-xl w-full mx-4` with responsive max-height and vertical scrolling.
- **Step Stacks**:
  - Template download card, CSV dropzone, and dry-run validation box stack vertically.
  - Validation metrics grid uses `grid-cols-1 sm:grid-cols-3 gap-2.5` to display `Total In Batch`, `Created (New)`, and `Skipped (Existing)` as vertical cards on mobile.
- **Line-Numbered Error Report**:
  - Sample error rows use bounded vertical scrolling (`max-h-36 overflow-y-auto break-words bg-black/25`) preventing viewport blowouts.
- **Action Buttons**:
  - Action footer uses `flex flex-col-reverse sm:flex-row items-stretch sm:items-center justify-end gap-2.5 sm:gap-3`.
  - Buttons enforce `w-full sm:w-auto min-h-[40px]`.

### 2.3 Setup Hub & Category Cards (`frontend/src/app/(admin)/settings/school-setup/page.tsx`)
- **Outer Shell**:
  - Outer wrapper uses `max-w-5xl mx-auto px-4` ensuring comfortable gutters on 390px screens.
- **Dual Scorecard Grid**:
  - Reflows from 2 columns to a single column (`grid grid-cols-1 md:grid-cols-2 gap-4`).
- **5-Gate Operational Checklist**:
  - Reflows responsively from 5 columns on desktop to 1 column on mobile (`grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-5 gap-3`).
- **8 Category Cards Grid**:
  - Reflows to single-column cards on mobile (`grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4`).
- **Next-Best-Action Banner**:
  - Fee pricing NBA banner uses `flex flex-col sm:flex-row items-start sm:items-center justify-between gap-3`. Direct action button has `w-full sm:w-auto min-h-[38px]`.
- **Category Card Links Empirical Resolution**:
