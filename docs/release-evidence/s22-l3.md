## 2. Key Delivered Components

### 1. Teacher Messages Page (`frontend/src/app/(teacher)/teacher/messages/page.tsx`)
- Server component enforcing RBAC guard `requireAuth(["TEACHER", "SUPER_ADMIN", "SCHOOL_ADMIN", "PRINCIPAL"])`.
- Calls `getTeacherConversations(school.id, ctx.userId)` to load allocation-scoped conversation threads.
- Injects `initialThreads` and `currentUserId` into `TeacherMessagesClient`.

### 2. Teacher Messages Client (`frontend/src/app/(teacher)/teacher/messages/TeacherMessagesClient.tsx`)
- **Conversation Thread List**:
  - Displays conversation threads with counterpart parent name, student name with class/section badge, subject line, latest snippet, timestamp, and unread counter badge (`{unreadCount} new`).
  - Top header displays total unread counter across all threads.
  - Zero mailto links: Clean empty state powered by `EmptyStateCTA` with title "No Parent Messages Yet" and hint "When parents of students in your assigned classes or subjects send academic inquiries, they will appear here."
  - Manual `Refresh` trigger with spin animation for on-demand inbox sync.
- **Active Thread Detail Surface**:
  - Back navigation button returning to thread list.
  - Full chronological message history:
    - Teacher messages: aligned right with emerald styling (`bg-emerald-950/60 border-emerald-800/60 text-emerald-100`) and read status (`Check` for sent, `CheckCheck` for seen).
    - Parent messages: aligned left with slate styling (`bg-slate-800/90 border-slate-700/80 text-slate-200`).
  - Automatically marks thread read on open via `markThreadReadAction(thread.threadId)`.
  - Sticky bottom reply box with `min-h-[38px]` textarea and `min-h-[38px]` send button.
