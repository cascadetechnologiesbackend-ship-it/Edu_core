## 1. Automated Lifecycle & State Transition Verification

Covered all sensitive HR operational flows in CI:

### A. Leave Request Lifecycle
1. **Creation**: `createLeaveRequest` validates active staff record and creates row with status `"PENDING"`.
2. **HOD Approval**: `approveLeaveRequest(..., "HOD", true)` sets status to `"HOD_APPROVED"`, records `hodApprovedById` and timestamp.
3. **HR Final Approval**: `approveLeaveRequest(..., "HR", true)` sets status to `"HR_APPROVED"`, records `hrApprovedById`, finds active academic year and staff balance for leave type, and accurately increments `usedDays`.
4. **Rejection**: `approveLeaveRequest(..., "HR", false, reason)` sets status to `"REJECTED"` and persists `rejectionReason`.
5. **Fail-Closed Auth**: Denies unauthenticated calls with `"Unauthorized"`.

### B. Payroll Run Lifecycle & State Lock
1. **Draft Generation**: `runPayrollForMonth` creates draft run, calculates actual gross, deductions, LWP days (from `HR_APPROVED` requests), attendance deductions, and inserts payslips for each staff member.
2. **Role Enforcement**: Unauthorized caller (e.g. `TEACHER`) is blocked with 403 / role not permitted.
3. **Approval & Lock**: `approveAndLockPayroll` transitions run status to `"APPROVED"`, sets `approvedById` and timestamp, and applies loan EMI deductions directly against `staffLoans.remainingAmount`. When loan reaches 0, transitions loan status to `"PAID_OFF"`.
