## 1. Compliance Standard: Mobile Law (AC-5 & PF-R00)

All role-based applications in SchoolMitra must strictly satisfy:
1. **Vertical Stack Reflow**: Grids must collapse to single-column (`grid-cols-1`) on mobile viewports ($\le 390$px).
2. **Zero Horizontal Overflow**: The root container must declare `overflow-x-hidden` and no child element may declare fixed pixel widths greater than 390px (`w-[>390px]`).
3. **Touch Target Size**: Every clickable link, button, and input element must satisfy minimum height $\ge 38$px (`min-h-[38px]`).
