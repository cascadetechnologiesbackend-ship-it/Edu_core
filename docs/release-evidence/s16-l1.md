## 1. Schema Artifacts Delivered

1. **Migration `0054_dual_role_teacher_assignments.sql`**:
   - `class_teacher_assignments`:
     - Primary key `id` (uuid default `gen_random_uuid()`).
     - Foreign keys to `schools.id`, `academic_years.id`, `sections.id`, `users.id` with `ON DELETE RESTRICT`.
     - Columns: `is_active`, `effective_from`, `effective_to`, `notes`, `created_at`, `updated_at`.
     - Invariant A: Partial unique index `cta_single_teacher_year_idx` on `(school_id, academic_year_id, teacher_id) WHERE is_active = true`. Enforces at most ONE active homeroom per teacher per academic year.
     - Invariant B: Partial unique index `cta_single_section_year_idx` on `(school_id, academic_year_id, section_id) WHERE is_active = true`. Enforces at most ONE active class teacher per section per academic year.
     - Lookup indexes: `cta_school_teacher_idx`, `cta_school_section_idx`, `cta_school_year_idx`.
   - `section_subject_teachers` extension:
     - Added column `academic_year_id` (uuid references `academic_years(id)`).
     - Added column `is_primary` (boolean NOT NULL default `true`).
     - Added column `periods_per_week` (integer NOT NULL default `5`).
     - Backfilled `academic_year_id` deterministically from `class_subjects` -> `classes.academic_year_id`.
     - Partial unique index `sst_active_primary_unique_idx` on `(school_id, academic_year_id, section_id, class_subject_id) WHERE is_active = true AND is_primary = true`. Defeats the bug where future `effective_to` allowed duplicates under `sst_active_unique_idx`.
   - `homeroom_report_remarks`:
     - New table for class teacher holistic report card remarks, conduct evaluations, and sign-offs (`student_id`, `academic_year_id`, `academic_term_id`, `remarks`, `conduct_grade`, `signed_off_by_id`, `signed_off_at`).
     - Unique constraint `uq_homeroom_report_remarks_student_term` on `(school_id, student_id, academic_term_id)`.
   - Backfill:
     - Seeded `class_teacher_assignments` from active `sections.class_teacher_id` rows joining `classes.academic_year_id` (`ON CONFLICT DO NOTHING`).
   - Row-Level Security:
     - Enabled RLS on `class_teacher_assignments`, `section_subject_teachers`, and `homeroom_report_remarks`.
     - Created tenant isolation policies bound to `school_id = NULLIF(current_setting('app.current_school_id', true), '')::uuid`.

2. **Drizzle Schema & Relations (`database/src/schema/academics.ts`)**:
   - Exported `classTeacherAssignments`, `homeroomReportRemarks`.
   - Updated `sectionSubjectTeachers` schema with new columns and indexes.
   - Added `classTeacherAssignmentsRelations`, `homeroomReportRemarksRelations`, and updated `sectionSubjectTeachersRelations`.

3. **Entity Catalog Registration (`packages/entity-engine/src/catalog/entityGraph.ts`)**:
   - Registered `class_teacher_assignments` under domain `ACADEMICS` with tenant isolation and relationships to schools, academic_years, sections, and users.
   - Registered `homeroom_report_remarks` under domain `ACADEMICS` with relationships to schools, students, academic_years, academic_terms, and users.
