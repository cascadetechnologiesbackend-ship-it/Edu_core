## 1. Objectives & Changes Made

1. **Eliminated Identity-Blind Placeholders in PTM Bookings**:
   - In `backend/src/lib/teacherEventEngine/snapshotAssembler.ts`, removed the hardcoded `studentName: "Student"` and `sectionName: "Section"` literals (lines 443-444).
   - Resolved child identities via `batchResolveStudentIdentities(schoolId, studentIds, txDb)`.
   - Set `studentName` to decrypted `student.fullName` and `sectionName` to `student.classSectionDisplayName` (e.g. `Class 6-A`).
2. **Enforced Open Decision 3 (OD3)**:
   - When a booking row references an unresolvable or deleted student (`!b.studentId || !student || !student.fullName`), the row is excluded entirely from `ptmBookingsToday`.
   - The platform never fabricates or renders degraded placeholder labels like `"Student of Section"`.
3. **Query Budget Retained**:
   - Lookups are executed in a single batched pass over `booking.studentId` values, maintaining strict $O(1)$ query overhead.
