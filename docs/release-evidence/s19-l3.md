## 1. Summary of Changes

Layer L3 addresses flaw **S19-F04** (Homework and lesson plan authoring have no operational UI in the teacher app) and operationalizes teacher authoring workflows.

### A. Homework Multi-Section Targeting (`homeworkActions.ts`)
- In `frontend/src/app/(teacher)/teacher/homework/homeworkActions.ts`:
  - Added support for `targetSectionIds?: string[]` to `createHomeworkAction`.
  - When target sections are passed, each target section is validated against teacher's S16 allocations via `sectionSubjectTeachers` or `classSubjects`.
  - Creates homework records across all specified sections in a single atomic transaction.
  - Automatically emits `AssignmentPublishedEvent` domain events for multi-surface downstream event propagation (Parent feed, Student Homework Center, Admin Subject Workspace).
  - Enforces DPDP PII scan (`scanContentForPII`) on title and instructions before persistence.

### B. Syllabus Coverage Toggle Mutation (`syllabusActions.ts` & `TeacherSyllabusClient.tsx`)
- In `frontend/src/app/(teacher)/teacher/syllabus/syllabusActions.ts`:
  - Implemented `markTopicTaughtAction`:
    - Validates teacher's active teaching allocation for the topic's subject/class (`sectionSubjectTeachers` / `classSubjects`).
    - Atomically updates or inserts `lessonPlans` records with `status = 'COMPLETED'` and effective `completedDate`.
    - Supports toggling back to pending (`status = 'PLANNED'`).
    - Emits `SyllabusTopicCoveredEvent` to the domain event log for whole-chain administrative and academic tracking.
    - Invokes `revalidatePath("/teacher/syllabus")`.
- In `frontend/src/app/(teacher)/teacher/syllabus/TeacherSyllabusClient.tsx`:
  - Upgraded topic cards with an interactive 1-tap toggle button (`data-testid="topic-toggle-${topic.id}"`).
  - Added optimistic local state management with toast feedback via `sonner`.
  - Bilingual button labels: *"Mark Taught"* / *"लंबित (पूर्ण करें)"* and *"Taught"* / *"पूर्ण"*.

### C. Teacher App Navigation Discovery (`more/page.tsx`)
- In `frontend/src/app/(teacher)/teacher/more/page.tsx`:
  - Added a dedicated **"Academics & Authoring"** section to the primary teacher navigation.
  - Exposes 1-tap links to:
    - **Homework & Assignments** (`/teacher/homework`)
    - **Syllabus & Curriculum** (`/teacher/syllabus`)
    - **Classes & Rosters** (`/teacher/classes`)
