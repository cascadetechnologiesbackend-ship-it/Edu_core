## 3. Truth Source Mapping for Live Queries

The live truth already exists in the system and will be channeled into `backend/src/lib/roleConsoleEngine.ts`:

1. **Principal Console Truth**:
   - Class Sections: `db.query.sections.findMany({ where: and(eq(sections.schoolId, schoolId), eq(sections.isActive, true)) })`
   - Teaching Staff: `db.query.staff.findMany({ where: and(eq(staff.schoolId, schoolId), eq(staff.status, "ACTIVE")) })`
   - Today's Student Attendance: Aggregated from `studentAttendance` where `attendanceDate` is today and `schoolId = schoolId`.
   - Pending Exam Verification: `db.query.examMarksLocks.findMany({ where: and(eq(examMarksLocks.schoolId, schoolId), eq(examMarksLocks.status, "SUBMITTED")) })`
   - Staff Attendance: Evaluated from `staffAttendance` if present for today (per OD3).
2. **Librarian Console Truth**:
   - Total Copies: Sum of `totalCopies` or count of active `bookCopies` for `schoolId`.
   - Available Copies: Sum of `availableCopies` or active copies with `isAvailable = true`.
   - Currently Issued: Count of `bookIssues` where `status = "ISSUED"` (or `returnedAt is null`).
   - Overdue Returns: Count of `bookIssues` where `returnedAt is null` and `dueDate < now()`.
   - Categories: Count of distinct `category` values on active books.
3. **Transport Manager Console Truth**:
   - Active Vehicles: Count of `vehicles` where `schoolId = schoolId` and `deletedAt is null`.
   - Configured Routes: Count of `routes` where `schoolId = schoolId` and `deletedAt is null`.
   - Pickup Stops: Count of `routeStops` linked to active routes.
   - Opt-in Students: Count of `studentBusPasses` where `schoolId = schoolId` (or active transport consents).
   - Real Maintenance Alerts: Vehicles where inspection / fitness dates are expired or flagged.
   - GPS Recency: Latest `gpsPings` timestamp per vehicle — displays real ping recency, never blanket claims.
