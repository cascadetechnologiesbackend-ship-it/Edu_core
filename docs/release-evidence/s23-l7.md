## 4. /boost Deep Architectural Analysis

### Topic 1: Today's Student Attendance Aggregation Under RLS and Query Budget
- **Problem**: In a school with 50 sections and 2,500 students, calculating today's attendance could easily exceed server action query budgets or cause latency spikes if queried naively per-section.
- **Architectural Solution**:
  - `roleConsoleEngine` issues a single filtered query against `studentAttendance` where `attendanceDate >= startOfDay` and `attendanceDate <= endOfDay` scoped to `schoolId`.
  - The aggregation computes `presentCount / totalMarked` in a single pass in O(N) memory without nested relational joins.
  - Non-school days (holidays) are filtered out via `status !== 'HOLIDAY'`.
  - When no records exist today, it explicitly returns `isMarkedToday: false`, rendering `"Attendance not taken today"` rather than a misleading `0%` or fabricated `94.2%`.
  - Enforced under `assertQueryBudget(..., { maxQueries: 6 })`.

### Topic 2: Overdue Issues & Vehicle Maintenance Boundary Conditions
- **Problem**: Null dates, soft-deleted records, and timezone offsets can cause false alarms or silent drops in circulation and fleet management.
- **Architectural Solution**:
  - **Librarian Overdue Logic**: Excludes returned items (`returnedAt is null` AND `status NOT IN ('RETURNED', 'LOST')`) and only flags overdue if `new Date(dueDate) < now`.
  - **Soft-Delete Invariant**: All queries explicitly enforce `isNull(books.deletedAt)` and `isNull(bookCopies.deletedAt)`.
  - **Transport Alert Boundaries**:
    - Expired: `fitnessCertExpiryDate < now` -> `"Fitness check due"`.
    - Expiring soon: `fitnessCertExpiryDate < now + 30 days` -> `"Fitness check due"`.
    - Real GPS status: `gpsPings` within the last 15 minutes mark a vehicle as active. Older timestamps display honest recency labels (`"Last ping Xh ago"`), and no pings display `"No recent GPS signal"`.

### Topic 3: Honesty Literal Detection Test Design Resistant to Bypasses
- **Problem**: Simple substring tests can be bypassed by string concatenation (e.g. `"2" + "4"` or template strings).
- **Architectural Solution**:
  - `s23-honesty-law.test.ts` scans both for prohibited JSX element child text (using regex `/>\s*<value>\s*</`) and asserts the positive presence of dynamic metric bindings (`metrics.<field>`).
  - By requiring both negative exclusion of banned literals and positive inclusion of domain engine accessors, bypasses via template concatenation or alternate element wrappers fail CI immediately.
