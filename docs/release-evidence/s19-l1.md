## 1. Summary of Changes

Layer L1 addresses flaws **S19-F01** (Silent fallback to "Free period" everywhere) and **S19-F03** (Lack of calendar awareness, Sunday falsely marked as "Day Complete").

### A. Academic Calendar State Machine (`snapshotAssembler.ts` & `types.ts`)
- Added `isRestDay`, `calendarEventTitle`, `isSetupMissing`, and `missingAllocationsSummary` to `TeacherDataSnapshot`.
- Enhanced `snapshotAssembler.ts` to query `academicCalendarEvents` using date range comparison (`startDate <= todayStr AND endDate >= todayStr`).
- If an event is found with `isWorkingDay = false`, marks the day as `isRestDay = true`.
- Evaluates `isSetupMissing`: If the teacher holds allocations in `sectionSubjectTeachers` but `periods.length === 0` on an instructional working day, extracts the allocated class-subject list as `missingAllocationsSummary` so the UI can honestly report that timetable publishing is pending.

### B. Sunday Resolution & Actionable Timetable Result (`classesActions.ts`)
- Fixed `getDayOfWeekEnum`: Returns `null` on Sunday (`day === 0`) instead of incorrectly falling back to `"MONDAY"`.
- Updated `getTeacherMyDayTimeline`:
  - Queries `academicCalendarEvents` for holidays / non-working events.
  - Queries `sectionSubjectTeachers` to cross-reference teacher allocations against `timetablePeriods`.
  - Returns `TeacherMyDayTimelineResult`:
    - `dayType: "INSTRUCTIONAL" | "REST_DAY" | "SETUP_MISSING"`
    - `holidayTitle?: string`
    - `isSetupMissing: boolean`
    - `missingAllocationsSummary: string[]`
    - `periods: MyDayPeriodItem[]`

### C. Honest Today Strip & Calm State (`TeacherTodayStrip.tsx` & `dashboard/page.tsx`)
- In `dashboard/page.tsx`, `isDayComplete` is strictly computed as:
  `isWorkingDay && totalSections > 0 && markedSections === totalSections`.
- On Sunday or rest days, `isDayComplete` is never asserted. `TeacherTodayStrip` renders the dignified `rest-day-badge` ("Rest Day: Recharge for tomorrow").
- On instructional days where timetable periods are missing but allocations exist, renders `setup-missing-badge` ("Setup Pending: Timetable not yet published").

### D. Honest MyDayTimeline Rendering & 1-Tap Completion (`MyDayTimeline.tsx`)
- On `REST_DAY`, renders `data-testid="timeline-rest-day-card"` with coffee icon, holiday/rest badge, and bilingual calm messaging.
- On `SETUP_MISSING`, renders `data-testid="timeline-setup-missing-card"` displaying all assigned class-subjects and an actionable CTA ("Notify School Admin").
- Dual-action completion:
  - 1-tap `Complete Lesson` button for rapid lesson completion satisfying AC-T7 1-tap click budget.
  - `Mark classwork done` button opening `AppModal` for detailed lesson coverage, DPDP-scanned notes, and optional homework creation.
