## 3. Truth Source Mapping & Invariant Architecture

To permanently resolve these flaws without breaking query budgets or tenant boundaries:

1. **Shared Identity Resolver (`backend/src/lib/teacherEventEngine/identityResolver.ts`)**:
   - Single-pass batched decryption and relation lookup for students, sections, and subjects.
   - Encapsulates DPDP decryption (`decryptData`) with zero per-row queries in loops.
   - Invariant: Zero placeholder strings emitted. Honest empty strings or `null` if unresolvable.
2. **Parity with Decision Surfaces**:
   - Leave queue card uses decrypted `fullName` matching `leaveActions.getTeacherPendingLeaveRequests`.
3. **Open Decisions Stance (OD1-OD3)**:
   - **OD1**: Periods whose `endTime` passed $\ge 30$ minutes ago today without a `COMPLETED` lesson plan derive `ClassworkPendingCard` (capped at 3 oldest).
   - **OD2**: Three insight models (`section_attendance_trend`, `homework_neglect_list`, `pre_publish_distribution`) derive only when data sufficiency gates are met; silent when insufficient.
   - **OD3**: Unresolvable identities (e.g. orphaned PTM bookings) are excluded from the feed entirely rather than rendered with placeholder dummy data.
4. **Universal Scroll-and-Click Law**:
   - All teacher feed cards reflow vertically with zero horizontal scroll at 390px mobile viewports.
   - All interactive touch targets $\ge 38$px.
