## 1. Summary of Changes

Layer L6 directly resolves **S19-F07 (P2 Data-Quality Defects)** and fulfills **AC6**:

### A. Fee Card Label De-duplication (`formatFeeTermName`)
- Created `formatFeeTermName` in `@/lib/utils` (frontend and backend).
- Prevents redundant concatenation where an existing suffix "Fee" (e.g., "Annual Fee", "Quarterly Fee", "Tuition Fee") produced duplicate labels such as `"Annual Fee Fee"` or `"Annual Fee Fee Paid"`.
- Appends `"Fee"` only if not already ending in a fee suffix (e.g. `"Term 1"` -> `"Term 1 Fee"`), and normalizes existing duplicates (`"Annual Fee Fee"` -> `"Annual Fee"`).
- Wired into `PaymentCard.tsx` (both proactive due and post-payment confirmed states).

### B. Single Source of Truth for Attendance Metrics (`calculateAttendanceMetrics`)
- Replaced divergent attendance calculations across parent surfaces with a canonical helper: `calculateAttendanceMetrics`.
- **Zero-Attendance Invariant**: When a student has zero attendance records recorded (e.g. newly enrolled), `calculateAttendanceMetrics` returns:
  - `totalDays: 0`, `attendedDays: 0`
  - `ratePercent: 100`, `rateRatio: 1.0`
  - Header and 30-day card show 100.0% and "0 of 0 sessions present", eliminating the defect where header showed 100% while profile card showed 0.0% (0 of 1 session).
- **Attendance Consistency**: Both `ParentIdentityHeader` and `ChildProfileView` consume the identical metrics; header normalizes ratios ($0..1$) and percentages ($0..100$) so they can never disagree.

### C. Name Assembly Cleanliness (`formatFullName`)
- Created `formatFullName(first, last, fallback)` in `@/lib/utils` (frontend and backend).
- Filters out empty values, `null`, `undefined`, as well as literal string artifacts `"null"` and `"undefined"` arising from legacy decryptions or missing last names.
- Replaced fragile string interpolations (`${first} ${last}`) across:
  - Teacher Dashboard greeting (`teacher/dashboard/page.tsx`)
  - Classes and Roster queries (`classesActions.ts`)
  - Homework Roster queries (`homeworkActions.ts`)
  - Grading Submissions & Exam Marks Entry (`gradingActions.ts`)
  - Parent Ward Resolver (`resolveParentWards.ts`) and Profile page (`parent/profile/page.tsx`)
